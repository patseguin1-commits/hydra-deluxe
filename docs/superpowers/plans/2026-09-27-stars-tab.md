# Stars Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "Stars" tab after "Dynamics" in the song details window. It shows Clone Hero's exact score cutoff for 1 through 7 stars and, for songs with solos, the total solo bonus as a separate figure.

**Architecture:** A new core module, `src/core/stars.{h,cpp}`, holds the star multiplier table and the cutoff math, copied from the game. It reads the chart's base score from one new `Path` method, `chart_base_score()`. `Path::avg_mult()` switches to that method too, so the base score is worked out in one place. The tab in `details_view.cpp` only draws what `star_cutoffs()` returns. Every number comes from the analyzed record, so no new chart reading or background job is needed.

**Tech Stack:** C++20, Dear ImGui, doctest (`hydra_tests`), Dear ImGui Test Engine (`hydra_uitest`), CMake via `build_cpp.ps1`.

**Spec:** There is no spec file. The design was approved in chat on 2026-09-27, and this plan records it in full below. The facts about the game come from decompiling Clone Hero v1.1.0.6142's `GameAssembly.dll`, summarized under "Where the math comes from".

## Where the math comes from

Clone Hero's code was decompiled on 2026-09-27. Here is what it does, in plain terms.

The game keeps a table of nine floats: 0.1, 0.5, 1.0, 2.0, 2.8, 3.6, 4.4, 5.2, 6.0. Each star's cutoff is the chart's base score times one entry, rounded up. The multiply is done in 32-bit float, then `Math.Ceiling`. The game counts stars from 0 upward: while your score is at least the next cutoff, it adds a star, and it stops at 7. Seven is a literal cap in the loop. So 1 to 7 stars use the first seven entries, and 5.2 and 6.0 are never reached.

The score compared against the cutoffs leaves out the solo bonus. The game adds the solo bonus to your score only after the stars are counted. The number on screen includes it.

The base score is 50 per gem. A cymbal gem is 65, and a ghost or accent note counts double. Hydra already adds up exactly this. It is `score_base + score_ghosts + score_accents`, the denominator `Path::avg_mult()` has always used. Every path hits every note, so it's the same on every path of a record. The solo bonus is `Path::score_solo`, at 100 points per note in a solo section.

The 32-bit float step almost never matters. Drum base scores are always multiples of 5, and for those the float result and the exact result agree for any realistic chart. It only shows up on large, odd base scores. At a base of 786,437, the game's 6-star cutoff is 2,831,173, while exact math gives 2,831,174. The code copies the game anyway, and a unit test pins that case.

## Global Constraints

The multipliers are exactly `0.1f, 0.5f, 1.0f, 2.0f, 2.8f, 3.6f, 4.4f`, in that order, for 1 to 7 stars. The cutoff is `ceil` of the product, and the product must be computed and stored as a `float` before `ceil`.

The base score has one source: `Path::chart_base_score()`, which returns `score_base + score_ghosts + score_accents`. `Path::avg_mult()` must call it instead of repeating the sum. The solo bonus has one source: `Path::score_solo`. The tab reads the record's best path (`record->best_path()`). The UI must not recompute any of these.

The tab's text is fixed:

- The tab label is `Stars`. It goes after `Dynamics`, and its ref is `##DetailsTabs/Stars`.
- The first line is `Base score: <n>`.
- When the solo bonus is above 0, the next line is `Solo bonus: <n> (not counted toward stars)`. When it is 0, that line isn't drawn.
- The table's columns are `Stars`, `Multiplier`, `Cutoff`, and, only when the solo bonus is above 0, `With full solo bonus`. It has one row per star, 1 to 7.
- The Stars cell is the star number. The Multiplier cell is `%.1f` of the multiplier (`0.1` … `4.4`). The Cutoff cell is the cutoff. The last cell is cutoff + solo bonus.
- Under the table goes `A star counts once your score, without the solo bonus, reaches its cutoff.`
- Every point value goes through `group_thousands`, so it reads like `123,456`.

The tab's states match the Paths tab word for word:

- While an analysis runs, it shows `render_analyze_progress(app)`.
- If the song hasn't been analyzed, it shows `After analyzing this song, star cutoffs will show up here.`
- If the record is stale, it shows the Paths tab's out-of-date warning, in `kWarningColor`.
- If there are no paths, it shows `No paths found.`

double Path::avg_mult() const {
    int64_t multscore = totalscore() - score_solo;
    int64_t basescore = chart_base_score();
    if (basescore == 0) return 0.0;
    return static_cast<double>(multscore) / static_cast<double>(basescore);

```cpp
// Clone Hero's star cutoffs, copied from the game (v1.1.0.6142, decoded from
// GameAssembly.dll on 2026-09-27).
//
// A star's cutoff is the chart's base score times a fixed multiplier,
// rounded up, with the multiply done in 32-bit float as the game does. You
// get a star when your score *without the solo bonus* is at or above its
// cutoff. The game stops counting at 7 stars.

#ifndef HYDRA_CORE_STARS_H
#define HYDRA_CORE_STARS_H

#include <array>
#include <cstdint>

#include "core/model.h"

namespace hydra {

inline constexpr int kMaxStars = 7;

// 1 through 7 stars. The game's table has two more entries (5.2 and 6.0),
// but its star counter stops at 7, so they are never reached.
inline constexpr std::array<float, kMaxStars> kStarMultipliers{
    0.1f, 0.5f, 1.0f, 2.0f, 2.8f, 3.6f, 4.4f};

// The score needed for `stars` (1..kMaxStars) on a chart with this base score.
int64_t star_cutoff(int64_t base, int stars);

// Everything the Stars tab shows, for one path of a record.
struct StarCutoffs {
    int64_t base = 0;        // Path::chart_base_score()
    int64_t solo_bonus = 0;  // Path::score_solo; not counted toward stars
    std::array<int64_t, kMaxStars> cutoffs{};  // [0] is 1 star
};

StarCutoffs star_cutoffs(const Path& path);

}  // namespace hydra

#endif  // HYDRA_CORE_STARS_H
```

Create `src/core/stars.cpp`:

```cpp
#include "core/stars.h"

#include <cmath>

namespace hydra {

int64_t star_cutoff(int64_t base, int stars) {
    // Stored as a float first: the game rounds the product to 32 bits before
    // rounding up, and that can move a large cutoff by one point.
    const float product = static_cast<float>(base) * kStarMultipliers.at(stars - 1);
    return static_cast<int64_t>(std::ceil(static_cast<double>(product)));
}

StarCutoffs star_cutoffs(const Path& path) {
    StarCutoffs out;
    out.base = path.chart_base_score();
    out.solo_bonus = path.score_solo;
    for (int stars = 1; stars <= kMaxStars; ++stars)
        out.cutoffs[stars - 1] = star_cutoff(out.base, stars);
    return out;
}

}  // namespace hydra
```

// ---- Stars tab -------------------------------------------------------------

// Clone Hero's star cutoffs for this chart. Every number is star_cutoffs()'s,
// read from the record's best path (the base score and solo bonus are the
// same on every path); this only draws them. The states match the Paths tab.
void render_stars_panel(AppState& app) {
    if (app.analyze_job) {
        render_analyze_progress(app);
        return;
    }
    if (app.viewed.status == store::RecordStatus::NotAnalyzed) {
        ImGui::TextUnformatted("After analyzing this song, star cutoffs will show up here.");
        return;
    }
    if (app.viewed.status == store::RecordStatus::Stale) {
        ImGui::TextColored(
            kWarningColor,
            "This record is out of date. To make sure you have the latest "
            "results, please re-analyze.");
        return;
    }
    if (app.viewed.record->paths.empty()) {
        ImGui::TextUnformatted("No paths found.");
        return;
    }

    const StarCutoffs sc = star_cutoffs(app.viewed.record->best_path());
    const bool has_solo = sc.solo_bonus > 0;

    ImGui::Text("Base score: %s", group_thousands(sc.base).c_str());
    if (has_solo)
        ImGui::Text("Solo bonus: %s (not counted toward stars)",
                    group_thousands(sc.solo_bonus).c_str());
    ImGui::Spacing();

    const int table_flags = ImGuiTableFlags_SizingFixedFit | ImGuiTableFlags_RowBg;
    if (ImGui::BeginTable("##startable", has_solo ? 4 : 3, table_flags)) {
        ImGui::TableSetupColumn("Stars");
        ImGui::TableSetupColumn("Multiplier");
        ImGui::TableSetupColumn("Cutoff");
        if (has_solo) ImGui::TableSetupColumn("With full solo bonus");
        ImGui::TableHeadersRow();

        for (int stars = 1; stars <= kMaxStars; ++stars) {
            const int64_t cutoff = sc.cutoffs[stars - 1];
            ImGui::TableNextRow();
            ImGui::TableNextColumn();
            ImGui::Text("%d", stars);
            ImGui::TableNextColumn();
            ImGui::Text("%.1f", static_cast<double>(kStarMultipliers[stars - 1]));
            ImGui::TableNextColumn();
            ImGui::TextUnformatted(group_thousands(cutoff).c_str());
            if (has_solo) {
                ImGui::TableNextColumn();
                ImGui::TextUnformatted(group_thousands(cutoff + sc.solo_bonus).c_str());
            }
        }
        ImGui::EndTable();
    }

    ImGui::Spacing();
    ImGui::TextUnformatted(
        "A star counts once your score, without the solo bonus, reaches its cutoff.");
}
